# تقرير tvhome — الحالة الكاملة

آخر تحديث: 8 نوفمبر 2026

## 1. الخلاصة

tvhome صار **المشغّل الافتراضي (Home)** على البوكس، بواجهة على نمط Apple TV (tvOS 26)،
وبيانات أفلام حقيقية من TMDB، وبحث حقيقي، وشاشة تفاصيل، وإعدادات كاملة،
وسكرين سيفر (Aerial + شاشة الصلاة)، وControl Center فوق أي تطبيق.

| البند | الحالة |
|---|---|
| المشغّل (Home) | ✅ مثبّت وهو الـ Home الافتراضي |
| التصميم (tokens + HIG) | ✅ `docs/HIG-tvOS.md` |
| بيانات TMDB (هيرو + صفوف + بوسترات) | ✅ حقيقية ومتحقَّق منها على الجهاز |
| البحث | ✅ ٦×٦ لوحة مفاتيح + شبكة نتائج، `batman` = 20 نتيجة |
| صفحة التفاصيل + deep link | ✅ `tvhome://detail?type=&id=` |
| الإعدادات | ✅ عام / سكرين سيفر / مواقيت الصلاة / الشبكة / حول |
| Aerial | ✅ 139 مقطع، حركة حقيقية (70% من البكسلات تغيّرت) |
| شاشة الصلاة | ✅ عربي RTL، مواقيت مطابقة لمرجع Aladhan |
| Control Center | ✅ Accessibility overlay فوق أي تطبيق |
| الاختبارات | ✅ 41 اختبار وحدة |
| المستودع | ✅ https://github.com/rashidhazim15-svg/tvhome (بدون أسرار) |

## 2. الجهاز

| | |
|---|---|
| الطراز | Wellbox، Amlogic `cupid` |
| النظام | Android 10 (API 29) |
| الشاشة | 1280×720 @ 160dpi |
| الذاكرة | 2GB RAM / 12GB تخزين (7.8GB فاضي) |
| المعمارية | armeabi-v7a |
| روت | ✅ `su` متاح عبر adb |

**المساحة:** ما في حاجة لفلاشة USB — الفاضي 7.8GB.

## 3. الأداء (أرقام حقيقية من `dumpsys gfxinfo`)

| الحالة | النتيجة |
|---|---|
| سكون (بدون لمس) | ~60 إطار/ث، median 13ms |
| تمرير سريع بالريموت | median 28ms (~35 إطار/ث)، ~75% إطارات متأخرة |
| وقت الإقلاع | لا يُقاس حاليًا |

سبب التأخير أثناء التمرير: جهاز 2GB + ظل البطاقات + تحميل الصور أثناء الحركة.
خطة التحسين موجودة في القسم 7.

## 4. يوتيوب — المشكلة والحل

**السبب الحقيقي (من logcat):**

```
GooglePlayServicesUtil: Google Play services out of date for com.google.android.youtube.tv.
Requires 203400000 but found 15181037
```

أي أن تطبيق YouTube TV الرسمي يحتاج Play services 20.34+، والجهاز فيه **15.1.81 (2018)**.
تحديث Play services على هذا البوكس خطر (قد يعطّل Play كله).

**الحل المنفَّذ:** SmartTube (`org.smarttube.stable`) — عميل YouTube مستقل لا يحتاج
Play services، كان مثبّتًا على الجهاز. الآن:

- يظهر في شبكة التطبيقات باسم **YouTube**.
- تطبيق YouTube TV الرسمي المعطوب مخفي تلقائيًا من الشبكة.

## 5. الأفلام والمباريات — الحد القانوني

لا يمكنني — ولن أفعل — إضافة مصادر بث مجانية لمحتوى مدفوع (دوري/مباريات/أفلام).
هذا قرصنة، وأي تطبيق يحويها يتعرض للحظر ومشاكل قانونية.

**البديل الذي أستطيع بناءه (قانوني ومفيد):**

1. **تفاعل مع التطبيقات المثبّتة:** زر "شاهد" في صفحة الفيلم يفتح Netflix/Prime/Shahid
   مباشرة على العنوان (deep link + بحث داخل التطبيق).
2. **تريلرات** لكل فيلم/مسلسل تفتح في YouTube (SmartTube).
3. **Watchlist** محلية (حفظ في المفضلة) + صف "أكمل المشاهدة" يقرأ من التطبيقات.
4. **صف رياضة** يفتح التطبيقات الرسمية المثبّتة (beIN/Shahid/SSC…) عند توفرها.
5. **محتواك الخاص** من فلاشة/شبكة عبر Kodi (مثبّت أصلًا).

## 6. الميزات التي أُضيفت في هذه الجولة

- إصلاح شبكة التطبيقات: كانت تسقط تطبيقات (Kodi, SmartTube…) إذا فشل تحويل
  البانر/الأيقونة؛ الآن كل تطبيق يظهر حتى لو فشلت صورته.
- إخفاء تطبيقات الزوائد (`wallpaper`, `gallery3d`, `music`).
- SmartTube ظاهر كـ YouTube، وYouTube TV المعطوب مخفي.
- تسريع النظام: `window/transition/animator` animation scale = 0.5.

## 7. الخطة القادمة (بالأولوية)

1. **جولة أداء**: تقليل كلفة الظل والرسوم أثناء تغيير التركيز، قياس قبل/بعد.
2. **Spotify مدمج**: شريط "الآن يُشغَّل" في المشغّل + أزرار في Control Center
   (يحتاج Notification Access، والتطبيق مثبّت).
3. **شعار الإقلاع**: استبدال `/system/media/bootanimation.zip` بأنيميشن على نمط tvOS
   (روت متاح، مع نسخة احتياطية وإمكانية رجوع). ملاحظة: لن أضع شعار Apple المحمي
   داخل المستودع؛ يمكن استخدام توقيع tvhome أو صورة خاصة بك.
4. **زر "شاهد" / تريلر / Watchlist** في صفحة التفاصيل.
5. **تحسينات بصرية**: انتقالات ناعمة، تأثير زجاجي أخف، أيقونات أوضح.
